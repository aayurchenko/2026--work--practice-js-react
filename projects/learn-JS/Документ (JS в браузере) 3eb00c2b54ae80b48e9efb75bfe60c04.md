# Документ (JS в браузере)

### DOM & BOM

Браузерное окружение 

Окружение - способность среды предоставить свою функциональность  для работы JavaScript.

Например, браузер предоставляет средства для управления веб-страницами. Node js делает доступными какие то серверные возможности и тд.

![{66071F29-5F4A-4DEA-850A-5F496DCABAD9}.png](66071F29-5F4A-4DEA-850A-5F496DCABAD9.png)

На картинке представлено, что доступно для JavaScript в браузерном окружении

Корневой объект `window` выступает в 2 ролях:

1 Глобальный объект для JS кода

2 Окно браузера и методы для управления им

Например, здесь мы используем `window` как глобальный объект:

```jsx
function sayHi() {
  alert("Hello");
}

// глобальные функции доступны как методы глобального объекта:
window.sayHi();
```

А здесь мы используем `window` как объект окна браузера, чтобы узнать его высоту:

```jsx
alert(window.innerHeight); // внутренняя высота окна браузера
```

## DOM (Document Object Model)

DOM - объектная модель документа, которая представляет все содержимое страницы в виде объектов, которые можно менять.

Объект `document` - входная точка, с его помощью мы  можем что то создавать или менять.

Например:

```jsx
// заменим цвет фона на красный,
document.body.style.background = "red";

// а через секунду вернём как было
setTimeout(() => document.body.style.background = "", 1000);
```

## DOM - дерево

Основой HTML - документа являются теги.

В соответствии с объектной моделью документа («Document Object Model», коротко DOM), каждый HTML-тег является объектом. Вложенные теги являются «детьми» родительского элемента. Текст, который находится внутри тега, также является объектом.

Все эти объекты доступны при помощи JavaScript, мы можем использовать их для изменения страницы.

Структура DOM 

```jsx
<!DOCTYPE HTML>
<html>
<head>
	<title>О лосях</title>
</head>
<body>
	Правда о лосях.
</body>
</html>

```

DOM - это представление HTML - документа в виде дерева тегов.  Пример:

Каждый узел этого дерева - объект.
