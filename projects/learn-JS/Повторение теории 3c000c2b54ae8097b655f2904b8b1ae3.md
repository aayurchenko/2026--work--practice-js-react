# Повторение теории

JS - синхронный, однопоточный, интерпретируемый, высокоуровневый, мультипарадигменный язык программирования с динамической типизацией, который используется для создания интерактивности на веб страницах.
 

Главные особенности: 

- Динамическая типизация - типы переменных определяются во время выполнения, а не на этапе компиляции. В процессе выполнения кода типы могут изменится (приведение типов).
- Прототипное наследование - вместо классов, в JS используется прототипная модель наследования. Классы являются синтаксическим сахаром над функциями конструкторами.
- Однопоточность - JS выполняется в одном потоке, но поддерживает асинхронность благодаря Event Loop, Web API и механизму коллбэков.

 

Парадигма программирования  - это совокупность идей и понятий, определяющих стиль написания компьютерных программ. (Обобщая - Подход к программированию)

Парадигмы программирования: 

1. Императивное программирование: мы пошагово говорим программе что именно делать.

    
    ```jsx
    const numbers = [1, 2, 3, 4];
    const result = [];
    
    for (let i = 0; i < numbers.length; i++) {
    	if (numbers[i] % 2 === 0) {
    		result.push(numbers[i]);
    	}
    }
    ```
    
    Сюда же часто относят процедурный стиль, когда код разбивается на функции - процедуры.
    
    ```jsx
    function calculatePrice(price, discount) {
    	return price - price * discount;
    }
    
    const price = calculatePrice(1000, 0.1);
    ```
    
2. ООП - Объектно - ориентированное программирование
Программа строится вокруг объектов, которые содержат данные и поведение
    
    ```jsx
    class User {
    	constructor(name) {
    		this.name = name;
    	}
    	
    	sayHello() {
    		console.log(`Привет, я ${this.name}`);
    	}
    }
    
    const user = new User("Alex");
    
    user.sayHello();
    ```
    
    Основные идеи ООП: 
    
    - **Инкапсуляция -** скрываем внутреннюю реализацию:
        
        ```jsx
        class BankAccount {
          #balance = 0;
        
          deposit(amount) {
            this.#balance += amount;
          }
        
          getBalance() {
            return this.#balance;
          }
        }
        ```
        
    - **Наследование -** один класс может расширить другой:
        
        ```jsx
        class Animanl {
        	speak() {
        		console.log("...");
        	}
        }
        
        class Dog extends Animal {
        	speak() {
        		console.log("Гав");
        	}
        }
        ```
        
    
    - **Полиморфизм -** одинаковый интерфейс может иметь разное поведение
        
        ```jsx
        dog.speak();
        cat.speak();
        ```
        
    
    - **Абстракция** - скрываем ненужные детали и оставляем понятный интерфейс.

Важно  учитывать: **JS** изначально использует прототипное наследование.  

### 3. Функциональное программирование

Главную роль играют **функции и преобразования данных**.

Например:

```jsx
const numbers = [1, 2, 3, 4];

const result = numbers
  .filter(number => number % 2 === 0)
  .map(number => number * 2);
```

Вместо пошагового изменения массива мы описываем:

> отфильтруй данные → преобразуй данные.
> 

Функциональный подход старается использовать **чистые функции**.

Например:

```jsx
function sum(a, b) {
  return a + b;
}
```

Для одинаковых аргументов она всегда возвращает одинаковый результат и ничего снаружи не изменяет.

Также желательно избегать мутаций.

### 4. Декларативное программирование

Мы говорим **что хотим получить**, а не подробно описываем, как это сделать.

Императивно:

```
const result = [];

for (const number of numbers) {
  if (number > 5) {
    result.push(number);
  }
}
```

Декларативно:

```
const result = numbers.filter(number => number > 5);
```

Второй вариант буквально говорит:

> дай мне числа больше 5.
> 

React — хороший пример декларативного подхода:

```
function User({ name }) {
  return <h1>Hello, {name}</h1>;
}
```

## Типы данных:

### Объект - структура данных, которая хранит данные в формате ключ - значение.

```jsx
const user = {
	name: "Alex",
	age: 25,
	isAdmin: false,
};
```

### Способы задания объекта:

1. Самый распространенный способ - литерал объекта.
    
    ```jsx
    const user = {
    	name: "Alex",
    	age: 25,
    };
    
    const user2 = {};
    
    // добавление свойств
    
    user2.name = "Alex";
    ```
    
2. Через new Object()
    
    ```jsx
    const user = new Object();
    
    user.name = "Alex";
    user.age = 25;
    ```
    

### Доступ к свойствам

1. Через точку

```jsx
const user = {
  name: "Alex",
  age: 25,
};

console.log(user.name); // Alex
console.log(user.age);  // 25
```

1. через квадратные скобки 
    
    ```jsx
    console.log(user["name"]);
    
    const key = "name";
    
    console.log(user[key]);
    ```
    
    А вот:
    
    ```
    user.key
    ```
    
    означает буквально:
    
    ```
    user["key"]
    ```
    
    а не `user["name"]`.
    
    #### Когда квадратные скобки обязательны
    
    Например, если ключ содержит пробел:
    
    ```jsx
    const user = {
      "first name": "Alex",
    };
    ```
    
    Так нельзя:
    
    ```jsx
    user.first name;
    ```
    
    Нужно:
    
    ```jsx
    user["first name"];
    ```
    
2. Динамические ключи
    
    Очень полезная возможность.
    
    ```jsx
    const key = "name";
    
    const user = {
      [key]: "Alex",
    };
    ```
    
    Получится:
    
    ```jsx
    {
      name: "Alex"
    }
    ```
    
    Например:
    
    ```jsx
    const field = "age";
    
    const user = {
      name: "Alex",
      [field]: 25,
    };
    ```
    

### Проверка наличия свойства

Есть несколько способов.

## `in`

```
const user = {
  name: "Alex",
};

console.log("name" in user); // true
console.log("age" in user);  // false
```

Важно: `in` проверяет также свойства, находящиеся в **цепочке прототипов**.

## `Object.hasOwn()`

```
Object.hasOwn(user, "name");
```

Для проверки именно собственного свойства:

Получим:

```
true
```

Современный вариант, который обычно предпочтительнее старого:

```
user.hasOwnProperty("name");
```

## Перебор объекта

У обычного объекта нет метода:

```
user.map()
```

или:

```
user.forEach()
```

как у массива.

Для перебора есть несколько основных способов.

---

# `for...in`

```jsx
const user = {
  name: "Alex",
  age: 25,
  city: "Moscow",
};

for (const key in user) {
  console.log(key);
}
```

Получим примерно:

```
name
age
city
```

Чтобы получить значение:

```jsx
for (const key in user) {
  console.log(user[key]);
}
```

Результат:

```
Alex
25
Moscow
```

Или сразу:

```jsx
for (const key in user) {
  console.log(key, user[key]);
}
```

---

## Нюанс `for...in`

`for...in` перебирает не только собственные свойства, но потенциально ещё и наследуемые enumerable-свойства.

Поэтому иногда пишут:

```jsx
for (const key in user) {
  if (Object.hasOwn(user, key)) {
    console.log(key, user[key]);
  }
}
```

---

# `Object.keys()`

Очень часто используемый метод.

```jsx
const user = {
  name: "Alex",
  age: 25,
};

const keys = Object.keys(user);
```

Получим:

```jsx
["name", "age"]
```

То есть это уже обычный массив.

Поэтому можно:

```jsx
Object.keys(user).forEach((key) => {
  console.log(key);
});
```

или:

```jsx
Object.keys(user).map((key) => {
  return user[key];
});
```

---

# `Object.values()`

Возвращает значения:

```jsx
const user = {
  name: "Alex",
  age: 25,
};

Object.values(user);
```

Получим:

```jsx
["Alex", 25]
```

Можно перебирать:

```jsx
Object.values(user).forEach((value) => {
  console.log(value);
});
```

---

# `Object.entries()`

Один из самых удобных способов.

```jsx
const user = {
  name: "Alex",
  age: 25,
};

Object.entries(user);
```

Получим:

```jsx
[
  ["name", "Alex"],
  ["age", 25]
]
```

То есть каждый элемент — массив:

```jsx
[ключ, значение]
```

Поэтому удобно использовать деструктуризацию:

```jsx
for (const [key, value] of Object.entries(user)) {
  console.log(key, value);
}
```

Результат:

```jsx
name Alex
age 25
```

Это очень распространённый паттерн.

---

# Разница между `for...in` и `for...of`

Это популярный вопрос на собеседованиях.

`for...in` перебирает **ключи**:

```java
const user = {
  name: "Alex",
  age: 25,
};

for (const key in user) {
  console.log(key);
}
```

Получим:

```
name
age
```

А `for...of` работает с **итерируемыми объектами**.

Обычный объект не является iterable:

```jsx
for (const value of user) {
}
```

Получим ошибку.

Но можно:

```jsx
for (const value of Object.values(user)) {
  console.log(value);
}
```

Или:

```jsx
for (const [key, value] of Object.entries(user)) {
  console.log(key, value);
}
```

Удобно запомнить:

```
for...in → keys
for...of → values элементов iterable
```

Хотя технически формулировка про `for...of` немного глубже: он использует iterator protocol.

## REST & SPREAD Опереаторы ( … )

Оператор SPREAD разворачивает массив с которым мы работаем

```jsx
const citiesRussia = ['Москва', 'Казань', 'Новосибирск'];

console.log(...citiesRussia) // (Набор строк) Москва Казань Новосибирск
```

Позволяет также разворачивать объекты

```jsx
const cities = {...obj} //Копирование объекта
```

Оператор REST 

Похож синтаксисом на spread, но все же другой оператор

Этот оператор собирает оставшиеся значения (в массив, объект итд)

```jsx
function sum(...numbers) {
console.log(numbers);
}
```

# Классы

Класс - это шаблон для создания объектов с определенными свойствами и методами.  Он позволяет один раз задать правило по которому будут работать все объекты, созданный с помощью этого класса.

Классы позволяют: 

- Создавать объекты с одинаковой структурой
- Наследовать свойства и методы от других классов
- Инкапсулировать логику (полная приватность в ES2022)

Пример создания класса и экземпляра класса

```jsx
class User {

	constructor(name, age) {  
		this.name = name;
		this.age = age;
	}

	//Метод класса
	greet() {
		console.log(`Я админ ${this.name}!`);
	}
}

//Создание объекта (экземпляра класса) с помощью класса
const admin = new Admin("Мария", 30);
admin.greet(); //Привет, я админ Мария!
```

Статические методы и свойства 

Принадлежат самому классу, а не его экземплярам.

```jsx
class MathUtils {
	static PI = 3.14

}
```
